# WEB-PAGE
Cognify Web Page is a modern and responsive front-end web project designed to demonstrate clean UI design, structured layout, and interactive user experience. This project focuses on building a visually appealing and user-friendly web interface using fundamental web development technologies.

The goal of this project is to showcase front-end development skills including layout design, styling, responsiveness, and basic interactivity. It can be used as a template or reference for beginners who want to learn how to build a professional-looking web page.
